# DTE Frontend

React 19 + Tailwind v4 + TypeScript, built by Vite into `dist/dte.umd.js` — an Airflow `react_apps` plugin bundle (plan 066). See `CLAUDE.md`.

## Dev

```bash
# 1. Start the backend (from repo root, in a Python venv with dte installed)
uvicorn dte.api.main:app --port 8000 --reload

# 2. Install + run the frontend
cd frontend
pnpm install
cp .env.local.example .env.local   # if the default URL isn't right
pnpm dev                            # http://localhost:3000
```

## Regenerating types

`src/lib/api-types.ts` is generated from the backend's `openapi.json`. Regen after backend schema changes:

```bash
# backend must be running on :8000
pnpm gen:types
```

## Structure

```
src/
  app/
    layout.tsx           # html + fonts + ThemeProvider + SwrProvider
    page.tsx             # redirect /  →  /pipelines
    (app)/               # routes sharing the sidebar shell
      layout.tsx
      pipelines/{page,new,[id]/{page,edit}}.tsx
      runs/[id]/page.tsx
      preview/page.tsx   # component gallery
  components/
    ui/                  # reusable design-system primitives (portable)
    builder/             # sources, steps, output, form composition
    app-sidebar.tsx
    pipelines-table.tsx
    theme-provider.tsx
    theme-toggle.tsx
    trigger-button.tsx
  lib/
    api.ts               # typed fetch client + named endpoint helpers
    api-types.ts         # generated by openapi-typescript
    swr-config.tsx       # SWR provider wired to apiFetch
    cn.ts
```

## Design system

Tokens live in `src/app/globals.css`. Everything under `src/components/ui/` imports only from itself + `cn.ts`. To port the design system to another project, copy `globals.css` + the `ui/` folder + `lib/cn.ts` and add the three Google Fonts (Outfit / Space Mono / Cormorant Garamond) to the target's root layout.
