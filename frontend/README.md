# DTE Frontend

React 19 + Tailwind v4 + TypeScript, built by Vite into `dist/dte.umd.js` — an Airflow `react_apps` plugin bundle (plan 066). See `CLAUDE.md`.

## Dev

There is no standalone dev server: the bundle needs the React globals Airflow provides. Start the compose stack from the repo root, then:

```bash
cd frontend
pnpm install
pnpm dev     # vite build --watch
docker cp dist/dte.umd.js dte-airflow-apiserver-1:/opt/dte/backend/ui/   # then reload /plugin/dte
```

`pnpm build` writes the production bundle; rebuild the image to ship it.

## Regenerating types

`src/lib/api-types.ts` is generated from the FastAPI app's `app.openapi()`, dumped in Python. No server needed:

```bash
./scripts/gen-api-types.sh   # or: pnpm gen:types
```

CI regenerates it and fails on a diff, so commit the regen with any backend model change.

## Structure

```
src/
  plugin.tsx     # route table; the default export Airflow renders
  pages/         # one page per route (detail?id=…)
  components/
    ui/          # portable design-system primitives
    builder/     # sources, steps, output, form composition
    pipeline/    # pipeline detail page panels
    run/         # run detail panels
  lib/
    api.ts       # apiFetch + named endpoint helpers
    api-types.ts # generated by openapi-typescript
    nav.tsx      # Link / useRouter over react-router, plugin-base aware
  dte.css        # tokens, mapped onto Airflow's Chakra variables
```

## Design system

Everything under `src/components/ui/` imports only from itself + `lib/cn.ts`, and the tokens in `src/dte.css` are Airflow's theme variables. See `CLAUDE.md` and `DESIGN.md`.
