# Plan 004 — UI

## Problem

There is no visual interface. Pipeline definitions must be written as raw JSON and POSTed to the API. The stated goal is a UI where non-technical analysts can build transformation pipelines without writing code.

## Stack

- **React 19** + **TypeScript**
- **Vite** (dev server + build)
- **TanStack Query** — async state, polling run status
- **React Flow** — DAG pipeline builder
- **shadcn/ui** + **Tailwind** — component library
- **Zod** — client-side schema validation matching the Pydantic spec

Frontend lives at `frontend/` in the monorepo root. The FastAPI backend serves the API; the Vite dev server proxies `/api` to it.

## Pages and flows

### 1. Sources page `/sources`
- List configured sources
- Add source: pick source_type (filesystem, s3, mongodb, postgres, ...), fill config dict via a dynamic form, set table name
- Preview schema: calls `GET /api/sources/{id}/schema` (new endpoint) → renders field tree with inferred types

### 2. Pipeline builder `/pipelines/new` and `/pipelines/:id`
- Left panel: source schema tree (drag fields into steps)
- Centre: React Flow DAG — each node is a step
- Right panel: step config form (changes by node type)
- Step types and their forms:
  - **Filter** — expression text box with syntax highlighting
  - **Rename** — field list with editable alias
  - **Retype** — field picker + type dropdown
  - **Map (lookup)** — key/value table editor
  - **Map (expression/calculation)** — output field name + expression box
  - **Sort** — field list + asc/desc toggles
  - **Aggregate** — group-by field list + aggregation rows (field, func, alias)
  - **Join** — left/right source picker + join key(s) + join type
  - **Pivot** — index picker, columns picker, values picker, agg func

### 3. Output mapper `/pipelines/:id/output`
- Field list from compiled preview
- Per field: rename (alias), type override, include/exclude toggle
- Output target: json_file path or postgres connection + table

### 4. Runs page `/pipelines/:id/runs`
- Trigger button → POST /api/pipelines/:id/trigger
- Run list with status badges (pending / running / completed / failed)
- Poll active runs every 2s via TanStack Query `refetchInterval`
- Completed run: show rows_written, duration, link to output

## New API endpoints needed (backend)

```
GET  /api/sources/{id}/schema        # run schema inferrer, return field tree
GET  /api/pipelines/:id/preview      # compile pipeline, execute on sample (1000 rows), return JSON
GET  /api/pipelines                  # list all pipelines (requires plan 003)
```
